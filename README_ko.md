# 한글이야기 노린 (HangleIyagi Norin)

**마지막 글자가 사라지지 않는 리눅스 한글 입력기 — 치는 즉시 완성된 글자가 나옵니다. Wayland·GNOME 에서 그대로.**

[English](README.md) · [한국어](README_ko.md)

## 왜 한글이야기인가

- **끝 글자가 사라지지 않습니다.** 기존 입력기는 "조합 중" 상태를 쥐고 있어서, 치다가 마우스를 누르거나 다른 칸으로 옮기면 마지막 글자가 날아가곤 합니다. 한글이야기는 조합 상태를 들고 있지 않고 완성된 글자를 바로 내보냅니다.
- **검색창이 마지막 글자까지 알아봅니다.** 글자가 이미 들어가 있으니, 치자마자 검색과 자동완성이 끝 글자까지 반응합니다.
- **더 적게 치고 더 빠르게.** `ㅏ` 만 쳐도 `아` 가 됩니다 — 초성 ㅇ 을 칠 필요가 없습니다. 키 수가 20~30% 줄고 타이핑 리듬이 끊기지 않습니다.
- **내 자판으로.** 두벌식·세벌식 390·세벌식 최종, 그리고 키보드 그림에서 키를 눌러 바꾸는 **사용자 자판**. 세벌식은 도깨비불이 없습니다.
- **영문으로 쳐 버렸어도.** 영문 모드에서 친 것을 한/영 전환 때 한글로 바꿔 줍니다.
- **어느 앱에서나.** GTK3·GTK4·Qt5·Qt6·XIM(터미널·Wine), 크롬·Tilix·구글 문서까지. X11 과 Wayland 둘 다.

## 기존 입력기와 비교

| | 기존 입력기 | 한글이야기 |
|---|---|---|
| 입력 방식 | 조합한 뒤 출력 | 완성 글자 즉시 출력 |
| 초성 ㅇ | 필요 | 불필요 |
| 끝 글자 소실 | 생김 | 없음 |
| 입력 지연 | 있음 | 거의 없음 |
| 지우기 | 조합 단위 | 키 단위 |

## 기능

- 두벌식 · 세벌식 390 · 세벌식 최종(391) · 사용자 자판 편집
- 한/영 전환 — 한/영키, Shift+Space, Ctrl+Shift, 원하는 키
- 영→한 자동 변환, 시작 모드 선택(영문 / 한글 / 이전 상태)
- 포커스가 바뀌면 자동 확정, 키 단위 빠른 삭제
- 단어 후보 창과 자동 완성, 사용자 사전 자동 학습
- 관리자 창(`hangleiyagi-manager`)에서 모든 설정
- 다른 앱이 입력 모드를 알 수 있게 D-Bus 신호 제공

## 다운로드

**[⬇ 최신 버전 받기](https://github.com/iyagicom/HangleIyagi/releases/latest)**

| 내 시스템 | 받을 파일 |
|---|---|
| Ubuntu 24.04 · 데비안 | **ubuntu24.04** 가 붙은 `.deb` |
| Ubuntu 26.04 | **ubuntu26.04** 가 붙은 `.deb` |
| 페도라 · openSUSE | `.rpm` |
| 아치 · 만자로 | `.pkg.tar.zst` |
| 그 밖의 리눅스 | `.zip` |

```bash
sudo apt install ./hanguliyagi_*_amd64.deb   # 우분투 / 데비안
```

설치한 뒤 **설정 → 시스템 → 언어 및 지원 → 키보드 입력기** 에서 **HangleIyagi** 를 고르고 다시 로그인하면 됩니다.
